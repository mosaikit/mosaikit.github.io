Dev kit

The kit is for whoever writes, tests, signs and ships a plugin for Mosaikit, or builds a product on the platform, without the source code of the platform. It holds the mosaikit-plugin command-line tool, the plugin SDK (Rust), the plugin UI API (@mosaikit/plugin-api), the documents, examples and Docker files. Each release of the platform has its kit archives on the releases page. Start from the Getting started document; the index is the dev kit README.

Verify a download

A release lists, for each kit archive, a signature (<archive>.sig), and the files SHA256SUMS and SHA256SUMS.sig. Put the files you downloaded in one folder and run:

sha256sum -c SHA256SUMS --ignore-missing
mosaikit-plugin self-update --from-dir <folder with the files> --trusted-key <public key> --check

The first command checks the hash of the archive. The second checks the signature of SHA256SUMS against the public key you pass, then prints the breaking changes of the release. Details: Releasing the kit.

Trust the key

The official kit archives and the official .mskp packages are signed with the same ed25519 key. Its public key is in trusted_key.txt inside every kit archive, and an installed kit uses it to check its own updates (mosaikit-plugin self-update). To be sure the key is not one that came with a tampered archive, compare it with the key published on this page. A server installs a package only if its signature verifies and the key is in its trusted_keys list (see Packaging and signing and Developer signing).

Public key (ed25519, base64):

NFOuLYouMh4B5PX99+IAf40mlQf1gHRXTXuqaOXyVCc=

It is the key that signs the kit release kit-v1.0.0-rc1 and it is the content of trusted_key.txt in its archives. To check a download without installing it: mosaikit-plugin self-update --check --from-dir <folder with the archive, SHA256SUMS and SHA256SUMS.sig> --trusted-key NFOuLYouMh4B5PX99+IAf40mlQf1gHRXTXuqaOXyVCc=.
